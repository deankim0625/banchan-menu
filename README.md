# 엄마손 반찬 메뉴판

손님은 QR로 오늘 메뉴·가격·남은 수량을 보고, 엄마는 휴대폰 입력판에서 고르기만 하면 되는 반찬가게 사이트.

## 구조

| 누가 | 어디서 | 무엇을 |
|---|---|---|
| 손님 | `docs/index.html` (GitHub Pages로 공개) | 한눈에 보기 / 사진으로 보기 |
| 엄마 | Apps Script 웹앱 `?page=admin` (비밀번호만 입력, 로그인 없음) | 오늘 판매 고르기, 수량 ＋/－, 가격 |
| 나 | 구글 시트 **반찬가게 입력판** | 반찬 목록 처음 등록, 가게 정보, 엄마 비밀번호 |

데이터 흐름: 엄마 입력판 → 구글 시트 → Apps Script(JSON) → 손님 사이트(1분마다 새로 고침)

## 처음 설정 (한 번만)

1. 구글 시트 **반찬가게 입력판** 열기
   - `반찬목록` 탭: 가게에서 파는 반찬을 전부 한 줄씩 등록. 사진 파일 이름은 `사진` 열에 (예: `sigeumchi.jpg`)
   - `가게정보` 탭: 가게 이름·영업시간·전화번호, **엄마비밀번호는 꼭 바꾸기**
2. 시트 메뉴 **확장 프로그램 → Apps Script**
   - `Code.gs` 내용을 `apps-script/Code.gs`로 바꿔 넣기
   - 파일 추가(＋) → HTML → 이름 `admin` → `apps-script/admin.html` 내용 붙여 넣기
3. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**, 액세스 권한: **모든 사용자**
   - 권한 허용 후 나오는 웹앱 주소(`https://script.google.com/macros/s/.../exec`) 복사
4. `docs/index.html`의 `const API_URL = "";`에 그 주소 넣기
5. 엄마 휴대폰: `웹앱주소?page=admin` 을 열고 홈 화면에 추가
6. GitHub Pages로 `docs` 폴더 공개 → 그 주소로 `qr-poster.html`의 QR 주소 바꾸고 인쇄

Apps Script 코드를 고친 뒤에는 **배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.

## 사진

`docs/photos/`에 반찬 사진을 넣고, 시트 `사진` 열에 파일 이름을 적습니다. 사진이 없으면 반찬 이름이 적힌 색 타일이 대신 나옵니다.
