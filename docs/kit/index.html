곳별 순서

카카오맵 등록돼 있음 · 전화번호 비어 있음

  1. 카카오맵 앱에서 "마니반찬 선학로" 검색 → 가게 화면
  2. 정보 수정 제안 (또는 사장님이면 카카오맵 비즈니스 / 내 장소 관리로 소유 확인)
  3. 전화번호 · 영업시간 · 홈페이지 · 사진을 위 내용으로 채우기

네이버 스마트플레이스 등록돼 있음 · 사장님 권한 받기 전

  1. 네이버 지도 마니반찬 화면 → "권한 받기" (리뷰 311개가 그대로 이어지게 새로 등록하지 말고 기존 업체 선택)
  2. 사업자등록번호 입력 + 사업자등록증 사진 올리기 → 네이버 검토 후 승인
  3. 기본 정보 · 소개 · 메뉴 · 사진 · 홈페이지(메뉴판) 입력

당근 비즈프로필 새로 만들기

  1. 당근 앱 → 나의 당근 → 비즈프로필 만들기
  2. 위 기본 정보 · 소개 · 사진 입력, 메뉴판 링크 넣기
  3. "당근 소식 첫 글" 올리기 → 이후 매일 오늘의 반찬 카드를 소식으로

구글 비즈니스 프로필 새로 만들기

  1. 구글 지도에서 "마니반찬 선학로" 검색 → 없으면 내 비즈니스 추가 (business.google.com)
  2. 업종 "반찬가게"(없으면 "식료품점"), 위 주소 · 전화 · 영업시간 · 메뉴판 링크 입력
  3. 소유 인증: 구글이 고르는 방법(가게 전화 · 문자 · 영상 · 우편)으로 → 가게로 오는 것만 엄마한테 부탁

각 서비스 화면 이름과 절차는 바뀔 수 있어요. 막히는 화면은 캡처해서 보내 주세요.
